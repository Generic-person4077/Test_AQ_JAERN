# Introduction
"A scholar in the ways of elemental magic, utilizing and manipulating the physical forces."  

A Mage's attack modifier costs (or MOD costs) are: __400, 500, 600__  

The primary attributes for Mages are PWR and INT, this is considered an **easy** class to play, and attribute distribution outside of these is quite flexible.  

Every Mage has access to the [[Elemental Magic/Elemental Core/]] category, which contains groups that are not connected to a particular element, but elemental magic as a whole.
There are 4 elemental categories (or elements) to chose from, each leaning toward different play-styles, for example, water magic is support-focused, while fire is damage-focused.  
Within each category, there are different spell groups, each mechanically and thematically different from other groups in the same category. Each element shares a spell group with the Element adjacent to it.  
Each group contains some number of spells, which can range from rank **1** to rank **16**.  

# Elemental Categories and Buying spells
Mages **must** choose an element before buying any spells, including the spells in Elemental Core groups.  
Mages may know spells in INT/2 elemental spell groups.  
Buying ranks of a spell group works similarly to buying ranks of a skill, you must start at rank 1 spell(s) in a group, and work your way up, spells cost $base*rank$ EXP. Elemental spells have a base cost of 300 exp. If a spell group has multiple spells of the same rank, you only need to buy one to move to the next rank
