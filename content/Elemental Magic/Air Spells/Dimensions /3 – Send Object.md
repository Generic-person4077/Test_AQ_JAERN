---
title: 3 – Send Object
---
==Time to Cast:== 1 round  
==Resist Check:== none  
==Target:== touch  
==Duration:== instantaneous  
==Area:== single object  
==Effect:== send small object  
To use this spell, the caster holds an object of 5 lbs. or less, and then sends it to a memlocked location.
